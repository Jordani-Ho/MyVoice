声音工坊

按住按钮说一段话，它就学会你的声音；之后想说什么就打字， 它用你自己的声音念出来。数据经你自己部署的后端转发给 ElevenLabs，不会经过其他第三方服务器。

1
填写 ElevenLabs API Key
在 ElevenLabs 后台「Profile → API Keys」里获取。Key 只保存在你当前浏览器的内存里， 刷新页面后需要重新填写，不会被发送到除你自己后端以外的任何地方。
2
按住说话，让它记住你的声音
按住下面的按钮说 5–20 秒（环境安静、吐字清晰），松开就会自动学习这段声音， 不用另外找文件上传。想换一段重新学，再按一次就行。
3
输入要合成的文字
支持中英文，建议单次不超过 2000 字。
4
生成语音
声音在第二步已经学过了，这里点一下就直接用那段声音合成。
合成结果
可以直接播放或右键另存为下载；刷新页面后需要重新生成。
