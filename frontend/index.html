声音工坊

上传一段 5–20 秒的清晰人声样本，克隆出你的专属音色， 再输入任意文字，用这个音色朗读出来。数据经你自己部署的后端转发给 ElevenLabs，不会经过其他第三方服务器。

1
填写 ElevenLabs API Key
在 ElevenLabs 后台「Profile → API Keys」里获取。Key 只保存在你当前浏览器的内存里， 刷新页面后需要重新填写，不会被发送到除你自己后端以外的任何地方。
2
上传参考音频
支持 wav / mp3 / m4a，建议 5–20 秒，环境安静、吐字清晰、不要有背景音乐。
3
输入要合成的文字
支持中英文，建议单次不超过 2000 字。
4
生成语音
首次生成会先克隆音色（耗时稍长），之后只改文字、不换音频时会直接复用已克隆的音色。
合成结果
可以直接播放或右键另存为下载；刷新页面后需要重新生成。
